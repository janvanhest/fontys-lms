# Portflow bij Fontys ICT

Je portfolio tool voor het verzamelen en delen van je leerproducten.

Tijdens dit semester maak je gebruik van de portfolio tool Portflow. In Portflow kun je je voortgang van je project(en) zichtbaar maken door producten te verzamelen en feedback te vragen aan docenten, medestudenten, experts etc.

## Portfolio aanmaken

Je vindt het portfolio in het linkermenu van Canvas. Gebruik de OvP-template met code **SSRXOKE** om de structuur snel op te zetten.

## Structuur van je portfolio

**Intropagina**: het eerste wat de lezer ziet. Neem op: profielschets met foto, naam, motto, onderwijsachtergrond, werkervaring, motivatie.

**Secties**: helpen overzicht te krijgen tussen verschillende semesters. Maak een sectie per semester.

**Collecties**: structureer je portfolio met collecties per project. Maak een collectie voor je groepsproject en eventueel je individuele project.

**Doelen**: breng structuur aan binnen een collectie per leeruitkomst (Analyse, Advies, Ontwerp, Realisatie, Manage Control, Professional Standard, Personal Leadership).

**Collection description**: geeft de lezer context. Neem op: project- en onderzoekscontext, doorlopen proces, positionering van de evidence, persoonlijke reflectie.

## Leerproducten

Voorbeelden: gemaakte beroepsproducten, opdrachten, presentaties, verslagen, performance assessments. Maximum van 500MB per bestand.

Voorzien altijd van een **evidence description**: wat het is, wat het doel is, waarom het bijdraagt aan de leeruitkomst.

## Portfolio inleveren

Maak eerst een snapshot (bevroren versie) via 'Create a snapshot'. Selecteer de collecties en bewijsmaterialen die je wilt opnemen. Lever het snapshot in via de opdracht in Canvas.
